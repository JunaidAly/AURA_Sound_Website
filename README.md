# AURA — premium audio concept
Designed and built for Junaid Ali's portfolio. Fictional audio brand; products, prices and specifications are illustrative, not a live shop.

## Run
Serve `dist/` with any static web server, for example `python3 -m http.server 8080 --directory dist`, then open http://localhost:8080. No build or dependencies required.

## Features
- CSS 3D speaker with pointer-controlled rotation and floating animation
- Three interactive finishes, motion pause and reduced-motion support
- Responsive collection and product dialogs
- Session-only product selection and removal (no checkout/backend)
- Keyboard-accessible native dialogs and comparison table

## Deploy
Publish `dist/` on GitHub Pages, Netlify or Vercel. The `.openai/hosting.json` file is for the accompanying Sites deployment and can be omitted elsewhere.

## Design
Warm ivory, burnt orange and botanical charcoal; Manrope / DM Sans typography with system fallbacks. All product visuals are original CSS geometry. Google Fonts requires internet; the layout remains usable without it.
